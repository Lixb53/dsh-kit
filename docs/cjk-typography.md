# 中文界面排版规范（CJK Typography）

适用于中文为主、可能中英混排的 Web 界面。目标不是「好看」，而是**读起来不费劲、看起来不像机翻模板**。

## 1. 字体栈

优先系统字体，避免为中文加载 10MB 字体文件；品牌字体只在标题层使用并做子集化。

```css
:root {
  --font-sans: system-ui, -apple-system, "Segoe UI", "PingFang SC",
    "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans CJK SC", sans-serif;
  --font-mono: ui-monospace, SFMono-Regular, "Cascadia Mono",
    "JetBrains Mono", Consolas, monospace;
}
```

- Windows 中文优先 `Microsoft YaHei`，macOS 优先 `PingFang SC`，Linux 用 `Noto Sans CJK SC`。
- 不要用「苹方」这类只存在于单一平台的字形名做唯一回退。
- 中文字重只有 Regular / Medium / Bold 三档可用，不要依赖 300/500 的细微差异表达层级。

## 2. 字号与行高

| 层级 | 字号 | 行高 | 用途 |
|---|---|---|---|
| 显示 | 32–48px | 1.2–1.3 | 页面唯一主标题 |
| 标题 | 20–24px | 1.35 | 区块标题 |
| 正文 | 14–16px | 1.6–1.8 | 段落、表单说明 |
| 辅助 | 12–13px | 1.5 | 时间、计数、脚注 |

- 中文正文行高低于 1.5 会明显拥挤；高于 1.9 会散。
- 行宽控制在 28–40 个汉字（约 640–800px），超过就分栏或加宽边距。
- 一个页面只允许一个「最大字号」，且它必须对应核心任务，不是营销口号。

## 3. 中英混排

- 中文与英文/数字之间加 1/4 空格（可用 `text-spacing` 或手工空格），不要用全角空格。
- 英文与数字使用同一字体族；等宽数字用于表格、金额、计数（`font-variant-numeric: tabular-nums`）。
- 单位与数字之间留空格：`12 MB`、`300 ms`、`¥ 1,280`。
- 不要给中文标题加 `letter-spacing` 拉开字距；需要呼吸感就加字号或留白。

## 4. 标点与断行

- 中文使用全角标点（，。；：？！），英文语境用半角；不要混用。
- 避头尾：句号、逗号、右引号、右括号不能出现在行首；左引号、左括号不能出现在行尾。CSS 可用 `line-break: strict` 配合 `word-break: normal`。
- 长英文串、URL、代码标识符允许 `overflow-wrap: anywhere`；正文段落不要用它，否则会出现奇怪的断词。
- 省略号用 `…`（一个字符），不用 `...`。

## 5. 控件

- 按钮高度 ≥ 36px，触控目标 ≥ 44×44（移动端）；文字按钮的可点区域要包住整段文字。
- 中文按钮文案 2–6 字最佳；不要用「点击这里」。
- 表单标签在上方而不是 placeholder 里；placeholder 只放示例值。
- 错误提示写「哪里错 + 下一步 + 示例」，例如「手机号应为 11 位数字，如 13800138000」。

## 6. 常见反模式

- 中文正文用 12px + 灰色（`#9CA3AF`）：对比度不足，读起来累。
- 标题用英文衬线字体配中文黑体：风格断裂。
- 全角标点与半角混排、中英文之间无空格：像机翻。
- 用 Emoji 当结构性图标：跨平台字形不一致，且屏幕阅读器会读出表情名。
- 表格里数字不用等宽：列对不齐，扫读困难。

## 7. 自检清单

- [ ] 正文 ≥ 14px、行高 ≥ 1.6、对比度 ≥ 4.5:1
- [ ] 中英混排有间距，数字等宽
- [ ] 标点全角，避头尾生效
- [ ] 只有一个最大字号，且对应核心任务
- [ ] 按钮/表单标签/错误提示符合上述写法
- [ ] 280px 宽度下不横向溢出，文字不被截断
